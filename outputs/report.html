How to read these numbers

  • All label metrics use successful predictions only, because a failed prediction has no labels to compare.
  • Strict accuracy counts each failed prediction as wrong, so it is the lowest the accuracy could be.
  • "n/a" means the metric is undefined because its denominator is zero, for example precision when nothing was predicted for that class.
  • Macro F1 is the plain mean of the F1 for PASS, FAIL and ESCALATE, so a rare class counts as much as a common one.
